# i18n.py

**简体中文** ｜ [English](i18n.en.md) ｜ [← 返回 README](../README.md)

运行时多语言

malight 的报错、提示与导出信息**默认输出英文**，一行代码即可切成中文

```text
import malight
malight.set_language("zh")      # 切成中文
malight.set_language("en")      # 切回英文（默认）
```

不想改代码时可用环境变量，适合 CI 与命令行脚本

```text
set MALIGHT_LANG=zh             # Windows
export MALIGHT_LANG=zh          # macOS / Linux
set MALIGHT_LANG=auto           # 跟随系统语言
```

优先级：`set_language()` > 环境变量 `MALIGHT_LANG` > 默认 `"en"`。

只影响**运行时消息**，不影响 API 名称与返回的数据（`kind` / `cmd` 这类
机器可读的值恒为英文 ASCII，便于程序判断）。

扩展自己的语言（繁体、日语…）

```text
from malight import i18n
i18n.add_messages("zh-TW", {"export.ok": "[malight] {kind} 匯出成功{tail}-> {path}  [{size}]"})
malight.set_language("zh-TW")   # 未翻译的词条自动回退英文
```

临时切换（不污染全局，适合测试或文档生成）

```text
with malight.use_language("zh"):
    pen.export_png()            # 这几行输出中文
```

## 类与方法

### 函数

| 函数 | 说明 |
|---|---|
| `normalize` | 把任意语言写法归一成**语言族**（`"en"` / `"zh"` / `"auto"`）。 |
| `get_language` | 当前**生效**的语言码（已做词条回退，即真正用于取词的那个）。 |
| `set_language` | 设置输出语言（全局生效，覆盖环境变量）。 |
| `reset_language` | 清掉显式设置，回到「环境变量 / 默认英文」的解析结果。 |
| `is_chinese` | 当前是否为中文输出。 |
| `t` | 取一条本地化消息并按关键字格式化。 |
| `available_languages` | 已注册词条的语言码列表。 |
| `add_messages` | 注册或扩充一种语言的词条（未翻译的词条自动回退到语言族、再回退英文）。 |

### `Language`

语言枚举（继承 str，可直接当字符串用）。

| 方法 | 说明 |
|---|---|
| `of(value)` | 把任意写法归一成 Language 成员。 |

### `use_language`

临时切换语言，退出 `with` 后自动恢复（适合测试与文档生成）。

## 完整示例

在 PyCharm 里点绿色三角直接运行，或命令行：`python malight/i18n.py`

```python
if __name__ == "__main__":
    import malight
    from malight import i18n

    # 1) 语言枚举：继承 str，可直接与字符串比较，f-string 得到裸值
    print("枚举    :", Language.EN, Language.ZH, "| ZH_CN is ZH:", Language.ZH_CN is Language.ZH)
    print("比较    :", Language.ZH == "zh", Language.EN == "en")

    # 2) 归一化：各种写法都能认，认不出的回退英文
    for raw in ("zh", "zh-CN", "zh_CN", "chs", "Chinese", "en-US", "japanese", None):
        print("  normalize({!r:>10}) -> {}".format(raw, i18n.normalize(raw)))

    # 3) 默认语言是英文，且支持环境变量覆盖
    print("默认    :", malight.get_language(), "(ENV {}={!r})".format(
        i18n.ENV_VAR, os.environ.get(i18n.ENV_VAR)))

    # 4) 同一句话，两种语言：导出信息 + 报错提示
    key = "export.ok"
    kw = dict(kind="PNG", tail="", path=r"C:\out\demo.png", size="12.3 KB")
    for code in ("en", "zh"):
        malight.set_language(code)
        ok, err = malight.t(key, **kw), malight.t("err.need_shapely")
        print("[{}] 导出信息 : {}".format(code, ok, code, ok))
        print("[{}] 报错提示 : {}".format(code, err, code, err))

    # 5) is_chinese / available_languages
    malight.set_language("zh")
    print("is_chinese  :", malight.is_chinese())
    print("已内置语言  :", malight.available_languages())

    # 6) use_language：临时切换，退出后自动恢复（测试/文档生成很有用）
    with malight.use_language("en"):
        print("with 内 :", malight.t("size.unknown"))
    print("with 后 :", malight.t("size.unknown"))

    # 7) 扩展一种自己的语言；没翻的词条自动回退英文
    malight.add_messages("zh-TW", {
        "export.ok": "[malight] {kind} 匯出成功{tail}-> {path}  [{size}]",
        "size.unknown": "大小未知",
    })
    malight.set_language("zh-TW")
    print("zh-TW       :", malight.t(key, **kw))
    print("未翻译回退  :", malight.t("err.no_board"), "  <- 回退英文")
    print("现在语言集  :", malight.available_languages())

    # 8) 复位：回到「环境变量 / 默认英文」
    print("reset 后    :", malight.reset_language())
```
