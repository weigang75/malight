**malight** is a Python toolkit for SVG vector drawing.
malight: SVG Pen Python Tools Short for **Ma(gic) + light**, pronounced close to "Ma Liang" (the legendary magic brush 神笔马良，shen bi ma liang). A Python toolkit for generating and manipulating SVG graphics, named after the magic brush tale.
It provides handy APIs to programmatically create, modify and export SVG graphics for diagrams, artworks, custom vector assets and automated drawing tasks.
